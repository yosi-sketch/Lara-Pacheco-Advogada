# Lara Pacheco de Figueiredo — Advogadas de Empresa

Site institucional de advocacia trabalhista e empresarial em João Monlevade, Minas Gerais.

## Desenvolvimento

Instale as dependências com npm install e inicie com npm run dev.
Abra http://localhost:3000. Valide com npm run lint e npm run build.

## Tecnologias e identidade

Next.js 16, React 19, Tailwind CSS 4 e Framer Motion.
O tema do Tailwind é definido em app/globals.css, usando @theme inline.
Dourados extraídos do logo (#e0b050, #f0c060, #805010), grafite e marfim.
Cinzel nos títulos, alinhada às letras clássicas do logo, e Plus Jakarta Sans nos textos.
